## Images, files, video, audio
Drop or paste an image straight into the page, or use `/image`: **Upload**, paste a link, add a **Caption**, drag the edges to resize. `/file`, `/video` and `/audio` work the same way. Uploaded files are stored on this device (in a team workspace: in the workspace).

## PDF
`/pdf` → **Choose PDF**: the document is shown in a viewer right on the page. **Show as file** turns it into a plain file block; **Show in the viewer** turns it back.

## Embeds
`/embed` and paste a link — or paste the link on an empty line and choose **Embed**. One embeds YouTube, Vimeo, Loom, Figma, Google Maps, CodePen, Google Docs, Sheets, Slides, Forms and Drive, Miro, Excalidraw, GitHub Gist, Spotify, SoundCloud, Typeform, Calendly, Airtable, CodeSandbox, Replit, X and PDF links. Other links become a **Web bookmark** card. Embeds run sandboxed.

## Blocks that link pages
- `/link to page` — pick an existing page; it shows as a block link (it also appears under **Linked from** on that page).
- `/page` — creates a new sub-page right here.
- `/breadcrumb` — the path to this page (workspace › parents › page); it follows renames and moves.

> Share links carry small images only; exports and published sites include the files they can.
