Type `/` on an empty line (or after a space) and keep typing to filter: `/todo`, `/table`, `/board`, `/chart`. <kbd>↑</kbd> <kbd>↓</kbd> pick, <kbd>Enter</kbd> inserts, <kbd>Esc</kbd> cancels. German names work too: `/aufgabe`, `/tabelle`.

The menu is grouped: **Basic** (text, headings, page, callout, quote, divider, table), **Lists** (bulleted, numbered, to-do, toggle), **Media** (image, bookmark, embed, file, video, audio), **Database** (table, board, list, gallery, calendar, timeline and chart views, linked database), **Advanced** (code, equations, Mermaid diagrams, table of contents, columns, tabs, synced block, button, spreadsheet, chart), **Inline** (mention, date, emoji, icon) and **AI**.

## Markdown shortcuts
Type these at the start of a line:
- `# `, `## `, `### ` — headings
- `- ` or `* ` — bulleted list, `1. ` — numbered list, `[] ` — to-do
- `> ` — quote, `>> ` — toggle, `!> ` — callout
- ```` ``` ```` — code block, `$$ ` — equation, `---` — divider

Select text for the formatting toolbar: bold, italic, underline, strikethrough, code, link, colour, **Ask AI** and **Comment**.

> Pasting a link offers to keep it as a link or turn it into a bookmark, an embed or a player.
