Open **Home → Start step by step** for the illustrated guide prepared in your workshop. The name, role and action buttons belong to your signed-in account. Screenshots show a test account; personal values remain protected.

## Your path
1. Check your own invited email and the correct team workspace.
2. Install, start and connect your personal laptop worker once. With Cloud selected, the laptop connects to the ONE team server. Afterwards use the same fixed starter.
3. Sign in to Atlas and create your own limited agent in the intended tenant. Configure its exact MCP address and agent token under **Settings → AI → MCP servers**. An invitation-link token does not replace an agent token.
4. Select the model for the connection test and explicitly enable your separate MCP permissions for **GitHub Copilot** and **Local/Ollama**. A discovered catalogue is not yet proof of a record read.
5. **Prepare Copilot test** selects an available Copilot route and fills in the read-only demo prompt. Check it and press **START** yourself.
6. After completion use **Prepare Atlas Flow test**. The shared model needs no personal model key, but Atlas still needs your own worker and access. Do not submit repeatedly while queued.
7. Check actual `atlas_whoami` and `atlas_get` calls, project and record. Then follow the guide to propose your own ONE start note and read it before applying it.

Preparing a test changes no device default and sends no model request. The buttons are disabled while work is running, a draft exists or unreviewed changes remain, preserving your work. If a worker, model or tested MCP connection is missing, finish that setup step first.

## Guests and help
Guests stay read-only: they can read the guide and shared content and open their personal Atlas access. This does not enable workers, model tests or edits.

After two targeted attempts, report only the step code and visible error. Keep tokens and complete access links out of screenshots and shared pages. The start checklist observes actual setup signals; model prose without tool evidence is not a successful Atlas test.
