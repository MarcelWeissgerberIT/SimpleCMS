## Offline
After your first visit One keeps everything it needs on the device — every view included. Without a connection, your pages and databases work as usual. Only things that need the internet wait: Claude, MCP servers, GitHub sync, webhooks, team sync.

## Install as an app
In One, **Install as app** is in the top-right toolbar; small screens show its download icon. It remains available in regular browser fullscreen too.

The website offers **Install as app** beside **Open the workspace**. In One use **Settings → General → Install One** or the workspace menu. The key remains available when the browser has not offered an install prompt: it shows instructions instead. It disappears when One runs installed.
- **Windows, Edge:** confirm the install prompt, or use **⋯ → More tools → Apps → Install this site as an app**. One can then be pinned to Start or the taskbar. No coding worker or separate Windows build is needed.
- **Mac, Safari (macOS Sonoma 14 or later):** open the workspace, then **File → Add to Dock** or **Share → Add to Dock**. Safari does not expose a website-triggered install prompt.
- **Chrome on Mac / Windows:** use the install icon or **⋮ → Cast, save and share → Install page as app**.
- **Android:** that key, or the browser menu → *Install app* (or *Add to Home screen*). Installed, One appears in the share sheet: share a web page, photos or files to One and they land in **Clippings** — see [Capture](help:capture).
- **iPhone / iPad:** see [iPhone & home screen](help:iphone).

The installed app has its own window and icon. Chrome and Edge use their browser profile's local data; Safari web apps and iPhone home-screen apps keep separate storage. Sign in to a team workspace again when needed. Export a local workspace before moving it between browsers; personal keys and connections are not automatically transferred.

**Installation is separate from cloud checkout.** Installing One does not make a team workspace local or disconnect its sync. Use the workspace's local-checkout controls for that. AI, remote MCP servers and team sync still need their connections. If your organisation manages browser installation, ask IT or keep using the browser tab.

## Updates
When a new version of One is live, a notice says **A new version of One is ready.** Click **Reload** — your work is saved first. If you ignore it, the old version keeps running; a part that is no longer on the server may then fail to load (e.g. *“One was updated while this tab was open”*) — reload then.

> **Settings → About** shows when the version you run was built.
