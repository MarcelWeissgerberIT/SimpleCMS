## Offline
After your first visit One keeps everything it needs on the device — every view included. Without a connection, your pages and databases work as usual. Only things that need the internet wait: Claude, MCP servers, GitHub sync, webhooks, team sync.

## Install as an app
- **Chrome / Edge (computer):** the install icon in the address bar, or the browser menu → *Install*.
- **Android:** browser menu → *Install app* (or *Add to Home screen*). Installed, One appears in the share sheet: share a web page to One and it lands in **Clippings**.
- **iPhone / iPad:** see [iPhone & home screen](help:iphone).

The installed app opens without browser chrome and uses the same data as the browser tab on that device — except on iPhone, where the home-screen app keeps its own storage.

## Updates
When a new version of One is live, a notice says **A new version of One is ready.** Click **Reload** — your work is saved first. If you ignore it, the old version keeps running; a part that is no longer on the server may then fail to load (e.g. *“One was updated while this tab was open”*) — reload then.

> **Settings → About** shows when the version you run was built.
