## Bilder, Dateien, Video, Audio
Leg ein Bild direkt in der Seite ab oder füge es ein, oder nimm `/bild`: **Hochladen**, einen Link einfügen, eine **Bildunterschrift** ergänzen, an den Rändern die Größe ziehen. `/datei`, `/video` und `/audio` funktionieren genauso. Hochgeladene Dateien liegen auf diesem Gerät (im Team-Workspace: im Workspace). Die Taste **KI** in der Leiste eines Bildes lässt Claude es beschreiben (Alternativtext + Bildunterschrift), seinen Text auslesen, seine Tabellen zu Tabelle, Tabellenkalkulation oder Datenbank machen oder eine Frage dazu beantworten — siehe [Claude für Bilder](help:ai-menu).

## PDF
`/pdf` → **PDF wählen**: Das Dokument erscheint in einem Betrachter direkt auf der Seite. **Als Datei zeigen** macht daraus einen einfachen Dateiblock; **Im Betrachter zeigen** wieder zurück.

## Einbettungen
`/einbetten` und einen Link einfügen — oder den Link in eine leere Zeile einfügen und **Einbettung** wählen. One bettet YouTube, Vimeo, Loom, Figma, Google Maps, CodePen, Google Docs, Tabellen, Präsentationen, Formulare und Drive, Miro, Excalidraw, GitHub Gist, Spotify, SoundCloud, Typeform, Calendly, Airtable, CodeSandbox, Replit, X und PDF-Links ein. Andere Links werden eine **Web-Lesezeichen**-Karte. Einbettungen laufen abgeschottet (Sandbox).

## Blöcke, die Seiten verlinken
- `/link zur seite` — eine bestehende Seite wählen; sie erscheint als Block-Link (und auf jener Seite unter **Verlinkt von**).
- `/seite` — legt hier eine neue Unterseite an.
- `/brotkrumen` — der Pfad zu dieser Seite (Workspace › übergeordnete Seiten › Seite); folgt Umbenennungen und Verschiebungen.

> Freigabe-Links tragen nur kleine Bilder; Exporte und veröffentlichte Websites enthalten die Dateien, die sie können.
