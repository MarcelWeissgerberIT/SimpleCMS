Öffne eine Seite und klick **Teilen** (oben rechts), oder ⌘K → *Seite teilen*.

Der **Freigabe-Link** enthält die Seite selbst, komprimiert in die URL. Wer den Link hat, bekommt eine schreibgeschützte Kopie dieser Version — spätere Änderungen ändern sie nicht. Empfänger können **In meinem Workspace speichern**.

1. Link **kopieren**. Die Anzeige zeigt seine Größe; sehr lange Links kürzen manche Chat-Apps und Mailprogramme — große Seiten schickst du besser als HTML-Datei.
2. Kleine Bilder reisen im Link mit; größere bleiben weg (der Dialog sagt, wie viele).

## Mit Passwort
Schalte **Mit Passwort schützen** ein und wähle eins (8 Zeichen oder mehr). Die Seite wird auf diesem Gerät verschlüsselt (AES-256-GCM), bevor der Link entsteht. Das Passwort steckt nicht im Link — schick es getrennt, z. B. per Telefon. Es gibt keine Wiederherstellung: Ohne Passwort kann niemand die Seite öffnen.

## Andere Formate
- **Als HTML herunterladen** — eine eigenständige Datei, öffnet überall.
- **Als Markdown kopieren** — für GitHub, Obsidian, READMEs.

> Freigabe-Links tragen nie Kommentare, Schaltflächen-Aktionen oder Live-Quellen von Diagrammen. Im Team-Workspace bietet der Dialog außerdem an, Personen einzuladen — sie bearbeiten live, mit einer Rolle.
