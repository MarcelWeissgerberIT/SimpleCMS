Pages now offer **Open thinking desk**, and overview cards offer **Add to desk**. Collect statements from pages, attachment excerpts and Atlas code references in one working area.

Six zoom levels turn dots into readable cards. Threads connect conflicts, support and dependencies. Human-confirmed decisions can prepare reviewable text changes. Evidence levels record rationale and supporting links. What-if results can be saved as separate scenario plans.

Each AI request uses the selected cards. Document changes require explicit adoption.
