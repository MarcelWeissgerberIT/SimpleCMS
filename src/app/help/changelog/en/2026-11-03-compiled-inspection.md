**My compiled tasks** now offers **New BA / PO task**: choose a source page, one of its actual headings or your own topic, then save a private recipe. Saved inputs appear as suitable fields. **Check what is still missing** explains local prerequisites without starting a model request.

**Flow and blocks** shows instruction order and data dependencies. **Quantum space** offers clickable cubes, dependencies and a **Dimension slice**. New run receipts retain actual compiler checks and the bound model packet; older entries show intended, open checks only. Historical evidence never replaces current approval.

BA/PO analysis no longer silently drops long paragraphs or short headings. Ambiguous sections stop before inference with real choices. Run receipts keep errors visible alongside partial answers. Full personal evidence loads only when a run is opened.


For shared Claude access, task startup waits for central availability. A temporarily unavailable configuration is explained as a connection problem, without asking a participant to enter a personal key.


For ambiguous Atlas transfers, ONE asks where the result belongs: **new records**, **updates to existing content**, or **comments**. The choice narrows this task’s permitted write tools. Target bodies are read before comments or updates; a transfer receipt distinguishes writes accepted by Atlas from results confirmed by read-back. Accepted partial steps remain visible after a later failure. The delivery choice does not approve domain decisions.


Run receipts now also cover ordinary terminal tasks, failed runs and stopped attempts. These historical entries are not executable programs. They retain the request, result or partial answer, error and recorded tool steps. History refreshes after saves and when returning; failed receipt saves remain visible and can be retried. Earlier responses that were never recorded are not reconstructed retroactively.


Page AI keeps the tool log, source receipts, errors and answer in one scroll area. Insert and other result actions remain separately accessible. A persistent notice counts failed and successful tool calls; **Show failed calls** jumps to the affected call and its request. Query syntax, rate limits and server failures have distinct guidance. An unknown cause is not presented as an invalid token or an offline worker.


For document-analysis requests on an empty page, ONE now explains before calling the model when only a title was supplied. Open and select the imported source or use AI on its file block. Atlas searches combining a topic with an overriding AQL query are held before dispatch for correction. Fact checks distinguish totals from observed tenant subsets and structured source links from records actually read or available as write targets.


Previously handed-off or uncertain welcome emails can now be prepared for resend per recipient. Review the recipient and preview, then explicitly send only that person another email. Sending history remains visible. New welcome emails include a personal single-use sign-in link (15 minutes), so no second verification email is needed. Opening the link alone does not consume it; the recipient confirms the displayed address. A mail-server handoff still does not confirm inbox delivery.

- When email is unavailable: owners can activate new prepared accounts through a personal single-use link without email; 24-hour expiry, existing accounts excluded, ownership checked again on redemption.

- Guided AI preparation buttons can bind an accessible source page: it opens as visible context before Start. Missing sources stop preparation; no inference starts automatically.
