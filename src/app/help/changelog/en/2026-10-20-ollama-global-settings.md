**Settings → AI** now has an **Ollama Cloud** card. **Set up API key and model…** opens the worker’s protected setup page. Set them once for every coding task using Ollama Cloud on that worker. The same entry is in **Coding worker** settings.

An offline worker leads to connection settings first. The key stays on the worker’s computer; One never reads or synchronizes it. This entry configures coding execution; browser agents and the AI terminal retain their own settings.
