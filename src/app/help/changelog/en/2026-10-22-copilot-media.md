Worker **1.26.0** lets account-advertised Copilot vision models receive selected images as in-memory attachments. PDFs are extracted locally as text; omitted figures and layout are explicitly disclosed. Scans and oversized documents stop before inference.

Help now includes the participant laptop start check, internal Git and Atlas. Copilot Free can be tested through the CLI with the offered `auto`; desktop app sign-in alone is insufficient. Image generation, native PDF visual inspection, Jev and unattended team-server runs still need their own supported path.
