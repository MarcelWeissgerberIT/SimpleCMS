Choose **Install One** in the website header or **Install as app** beside **Open the workspace**. The same entry remains in **Settings → General** and the workspace menu. It uses the browser’s native prompt when available and otherwise shows the steps for your browser.

Windows uses Edge or Chrome. Safari on Mac uses **File → Add to Dock** (macOS Sonoma 14 or later). No coding worker or separate Windows package is required. The button disappears while One runs installed.

Installation keeps cloud checkout separate: a team workspace continues to use its cloud connection. Safari web apps can have separate storage, so sign in again or export a local workspace before moving it between browsers. See [Offline, app & updates](help:offline-app).
