title: Work in ONE first
summary: Prepare pages without Atlas and save answers as reviewed ONE pages.
---

You can prepare content in ONE even when no Atlas record exists. Include “Only in ONE” in your request. That task does not load Atlas tools or Atlas instructions; it still needs your configured model access.

A completed terminal answer offers **Prepare as a ONE page**. Choose its title and location, review the proposed page and click **Apply**. Saving needs no additional model request. Team workspaces initially select private storage; you can choose a visible workspace page instead.

Atlas is a separate, explicitly requested transfer. Create new records, update existing content or add comments. Creating a record does not require a pre-existing target record ID. Permissions, project, content and duplicate checks still apply.

When an Atlas page request ends without a confirmed source read, ONE asks the model for that read once. If it still does not happen, the error explains the missing source instead of showing a generic compiler failure. Accepted writes are not replayed.
