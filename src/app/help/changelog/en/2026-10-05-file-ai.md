Every file block now has an **AI** key in its bar and a **Claude** group in its block menu ⋮⋮ — for your uploads and for [mail attachments](help:gmail-sync) alike:

- **PDF** — **Summarise**, **Extract the text as a page** (headings kept), **Extract the tables** (→ table, spreadsheet or database), **Ask about the file…**
- **Word, HTML, Markdown, RTF, text** — **Open as page**, converted right here: headings, lists, tables and links stay.
- **CSV, TSV, Excel** — **Import as database…** with typed columns and a preview, or **Open as spreadsheet**; a workbook's sheets to pick from.

Entries marked **LOCAL** never leave your device. A file goes to Anthropic only with the Claude actions — a PDF up to about 23 MB and 600 pages; larger ones are refused before anything is sent. An HTML attachment becomes a page without scripts or tracking pixels. Everything runs in the background and lands in one step you can undo.

> Tip: in the AI terminal, <kbd>Mod+Shift+J</kbd> on a selected file block adds it as a reference — the next task reads the file.
