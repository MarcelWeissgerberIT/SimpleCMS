**Open at source** now takes you to the selected mock note, finding or requirement in its exact version. Saved-result links open the accepted report or patch. Links keep their destination when a block moves to another page. A missing version is explained; opening a link never accepts a proposal.

The **work overview** remembers your search, filter and reading position when you return from a source. This view stays in this tab's memory and resets when the access context changes. An accepted report's open findings remain visible even when a newer run fails.

The background task bar shows the current source read or action and offers **Open task source**. You can return to the original task page while the work continues. On phones, the quick-capture button leaves the task bar unobstructed.

**Resume analysis** now explains expired checkpoints and missing source pages. The overview closes only after resumption starts. Unsaved patch edits stay intact when a link requests another version. Recovery still checks sources again and does not repeat external writes.

On phones, folded sidebar sections also remain reachable when scrolling to their controls.
