Type `/mock` on an empty line and choose **UI mock from Atlas**. Enter the design MD, requirement record and request. **Prepare in AI terminal** carries the request over; start generation there.

Select the result in the block and choose **Use preview in block**. The static preview stays saved on the page and opens full screen. HTML/PNG export and Atlas attachments remain on the result card in the terminal.

After this update, older open cloud tabs need a reload before editing again.
