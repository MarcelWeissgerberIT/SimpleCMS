Open **Work overview** in the AI terminal to find pending mock notes, design-system Markdown changes, approvals, findings and failed analysis stages. Entries lead to their original location; proposed text edits open their individual before/after review.

**Evidence links** connects saved findings, code evidence and requirements through shared sources. Missing links remain visible. Code loads only when opened through your personal connection. Historical evidence does not attest the current branch. Creating source-reference subpages remains optional.

**Runs & cost** shows known costs per terminal task and saved pipeline stage, including failures. Saved terminal checkpoints show progress and cost. Resuming rereads sources without replaying writes. Checkpoints retain the existing 24-hour lifetime on this device.

Before a new terminal task, inspect selected sources and an estimate for known text. Further reads and history add cost; the governor manages actual budgets.

Under **Reuse**, prepare a private workflow from completed analyses. Choose sources and confirm the scope for each new run. This generates a document analysis from fresh page contents; use the code-analysis block for a new repository investigation.
