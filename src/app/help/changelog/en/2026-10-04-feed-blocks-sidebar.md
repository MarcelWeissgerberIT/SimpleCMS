**Feed** is a new database view: each entry is a card with its properties and its content, newest first — for announcements, journals and blog-like databases. **Show more** expands a post in place.

New blocks in the `/` menu:
- `/form` (German `/formular`) — a form with three starter questions in one step.
- `/breadcrumb` — the path to this page; `/link to page` — a block link to an existing page.
- `/4 columns` and `/5 columns`; `/pdf` shows a PDF in a viewer right on the page.
- More embeds: Google Docs, Sheets, Slides, Forms and Drive, Miro, Excalidraw, GitHub Gist, Spotify, Typeform, Calendly, Airtable, CodeSandbox, X and more.

In the sidebar a database now opens like a folder: its entries in the order of its first view, **+** adds one, and dragging a page onto a database makes it an entry.
