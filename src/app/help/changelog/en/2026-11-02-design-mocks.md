# BA/PO mocks: preview in ONE, files on the Atlas record

`/mock <requirement>` lets the selected model prepare a static HTML/CSS proposal from freshly read Atlas requirements, components and design tokens. The card offers preview, HTML download, rendered PNG and a source receipt.

Attach to Atlas record sends HTML, PNG and the receipt directly through your personal Atlas connection. ONE does not store mock files in its file library. Source changes stop publication; Atlas confirms actual file hashes. Missing design components cannot be silently substituted. Semantic and visual acceptance remain human decisions.
