**`one:` in a page** opens a menu of what is close by: the pages and entries on the **same level** as this page, then those **inside** it. Keep typing to search every page and entry by title; <kbd>Enter</kbd> links it like `@` does.

**In the AI terminal**, `one:` does the same — the page goes along as context. A server's codeword at the start of a prompt (e.g. `kb:`) lists that [MCP server's](help:mcp-servers) tools from its connection test: pick one with <kbd>Tab</kbd>, and Claude is told to use exactly that tool.

**Copy for AI context** (page menu, sidebar, ⌘K) puts a page on the clipboard as Markdown — for Claude Code or any chat.
