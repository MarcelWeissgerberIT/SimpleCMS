Click into a page table and use **Fill existing cells with AI** in the table toolbar. Choose up to 30 text cells, enter source notes, and pick the provider and model for this request. Shared local text models use the same action.

Review each **Before → Suggestion** before applying. ONE addresses the existing cells, saves a version and retains the table layout, surrounding plates and other inputs. Changed target cells or table structure stop a stale proposal. Rich cells stay manual. Claude/Copilot agents can use the matching cell tools and stage their changes for review.
