There are two Claudes at work. **Your MCP servers in One** (Settings → Claude AI → MCP servers) serve One's own Claude: the AI menu, the terminal, agents. The coding worker runs **Claude Code on your computer** — and there it gets only One's task tools, unless the worker's setup page allows more.

The coding panel now shows that line for every task: **Claude Code · MCP** with the servers this task's stages may use — the repo's **Own MCP servers for Claude Code**, or, for a task without a repository, the worker's **Tasks without a repository — own MCP servers** — or *only One's task tools*.

When the task's text mentions one of your MCP servers (by its name or codeword) that Claude Code may not use there — or MCP at all while it has none — the panel says so and **Open the setup page** takes you there. Enter the name as `claude mcp list` shows it on your computer, save, then run the task again.
