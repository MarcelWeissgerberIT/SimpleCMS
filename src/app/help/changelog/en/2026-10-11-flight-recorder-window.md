**Read it.** Click a run's flag (or set a window with <kbd>[</kbd> / <kbd>]</kbd>) and press <kbd>↵</kbd> — or **Read window** on the plate. The dialog lists every place the window changed: schema, views, pages, rows, new rows. <kbd>↑</kbd> / <kbd>↓</kbd> walk the list; beside it, the values before → after and the text word by word, in ink.

**Held: changed since.** A place someone changed after the run — you, a colleague, another agent — carries a diamond on the tape and an orange mark in the list: *2 rows changed since (you) — they are held.* What another writer did in the middle of the run is marked *contains changes by …*, never counted as the run's.

**Honest about gaps.** A window that cuts a writer's stretch reads *Partly*, with a key that brackets it whole; when a tab closed before it wrote its record, the window says *Possibly incomplete*.

**Incident report.** **Report** downloads a Markdown file: the window, every writer in it, what changed — titles, property names, counts and times, never a value or a line of text. Made when you press it, stored nowhere. Reading changes nothing. More in [Flight recorder](help:flight-recorder).
