Add the **Worker setup / download** action to a page button. It opens your personal Coding worker settings. Only the download there creates the file paired with your account, browser and workspace; the page stores no worker token.

Code blocks have **Copy** at the top right. The button only copies the command to the clipboard and never executes it. On translated live pages, navigation and worker-setup buttons remain usable while writing actions remain disabled. Guests, locked pages and shared previews gain no new execution rights.
