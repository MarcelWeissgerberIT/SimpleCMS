Worker **1.27.0** lets you select a Copilot model per coding task and BA, Coding or QA role. Role defaults are copied on task creation; your task choice takes precedence. The private worker default remains the fallback.

The account catalog supplies available models and supported reasoning levels. Context follows the advertised model limit up to 262,144 tokens; `auto` stays conservative. **Run receipts** show requested and reported models, tokens, stage, outcome and available quota data. Missing values and money amounts remain unknown. Guided acceptance includes a summary for the prepared Atlas handoff.

Read more: [GitHub Copilot in One](help:copilot-coding).
