summary: Choose the Atlas destination, verify identity and read the required original sections.

Atlas write requests in the page dialog now use the same workflow as the AI terminal: new records, existing content or comments. Text editing stays in the page dialog.

For “close the Atlas ticket”, ONE distinguishes **resolve questions and keep ticket status** from **close the ticket status**. The first choice prevents changes to status and other fields.

For “do that on my behalf”, ONE verifies the current personal Atlas identity before asking the model. Names inside page text do not determine the requester. Checking identity grants no additional permissions.

Long results can be searched by section or literal text without downloading them again. If a draft discusses named sections that have not been read, ONE requests one bounded correction using the original passages. A partially read body cannot be replaced in full.

These changes repair the workflow. They do not approve domain decisions or repeat earlier writes.
