Each stage that runs Claude Code — plan, implement, document — can now name its **model**. In **Pipeline** (on #/coding) open a stage's details and pick **Opus**, **Sonnet**, **Haiku**, **Fable** or **Own…** for any other model name; **Standard** keeps the worker's default (the repo's model in `worker.json`, else Claude Code's). The model shows as a small chip in the stage's row.

Plan with a strong model, let a faster one implement — or the other way round. For a single task, **Model** in the coding panel (next to Approvals) sets one model for all of its Claude Code stages, on this device.

While a stage runs, a chip under **Now** shows the model Claude Code really uses, and the log names the one the worker passed on. A stage with a model needs worker 1.5 — an older worker never gets it: download it again from #/coding. More in [Coding pipeline](help:coding-pipeline).
