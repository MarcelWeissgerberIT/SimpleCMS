Hover an image and press the **AI** key in its toolbar — or open the block menu ⋮⋮ (<kbd>Alt+Enter</kbd>) → **Claude**, or **Ask AI** on a selection that holds the image:

- **Describe the image** — an alt text and a caption to edit, then apply both in one step.
- **Read out the text** — everything written in the picture as Markdown, inserted below it.
- **Image → table** — every table in the picture with its header row: **Insert as table**, **as spreadsheet** (numbers as numbers) or **as database** (with the preview first).
- **Ask about the image…** — any question; the answer goes below the image or to the clipboard.

They run in the background like any AI request. The picture goes to Anthropic only with these actions, scaled down to at most 1568 px. A web image whose site doesn't let One read it can be uploaded as a copy.

> Tip: in the AI terminal, <kbd>Mod+Shift+J</kbd> on a selected image adds it as a reference — the next task sends the picture along.
