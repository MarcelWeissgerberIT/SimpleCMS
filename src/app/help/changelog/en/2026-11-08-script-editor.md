The workbench separates **Edit → Dry run → Run**. Its dry-run status applies to the exact code that was tried, and changes invalidate that status. Results from earlier edits are marked clearly. Add a purpose above the code so others can understand when to use the script; the field saves when you leave it. **Help & functions** searches function names and descriptions. **AI assistance** has its own tab; proposed code is reviewed before it is accepted.

The script editor now has literal **Find and replace**, case matching, next and previous match navigation, and **Go to line**. Replacing all matches is one undoable edit. Search fields do not start a script.

**Focus on code** makes room by hiding the reference pane or query builder. Line wrapping remembers your preference on this device. A save indicator shows when your code has reached the workspace; cloud synchronization remains visible separately. Evaluating a selection also saves pending edits first.
