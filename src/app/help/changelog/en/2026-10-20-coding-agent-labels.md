The Preflight permission lamp now reads **Agent wants**. Its rules, confirmation prompts and answer fields refer to the coding agent, so the overview fits Claude Code, Codex and local models.

Task questions, permission cards and permission notifications name the agent selected for that task: **Claude Code**, **Codex** or **Local · Ollama**. Unknown task choices use the neutral label Coding agent. Permission controls and worker routing behave as before.
