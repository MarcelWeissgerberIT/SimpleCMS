**Work overview** is now available in the sidebar and command search. See open work, pending decisions, sources requiring review and saved results. Current terminal work shows its context and actual latest activity; document pipelines link to the running stage.

**Review difference** opens the selected proposal in the terminal. A shared workflow in terminal results, mocks, code analyses and patches shows request, work, proposal, review and adoption, together with the actual saved state and next action. Acceptance in One remains separate from external publication.

**Evidence links** connects mocks and findings through identical recorded sources. A reported Atlas change highlights possible impact without claiming that all linked results are incorrect. Code connections include the saved snapshot. Opening this overview does not automatically read or modify external sources.

Mock history links associated feedback, AI rationale and your assessment to the original marked location. Code-analysis version changes jump to the affected finding. Saved terminal work shows its original page and next step; resuming remains an explicit action on this device.

**New task** guides requirements, UI feedback, decision briefs and follow-ups on code reports. A bounded goal and source pages are required; missing setup is explained. Sources are read afresh when the workflow runs. Preparing and saving do not start model calls. The technical definition is optional and collapsed.

The new views use One colours, visible keyboard focus and narrow layouts. Escape also closes the prepared-workflow dialog.
