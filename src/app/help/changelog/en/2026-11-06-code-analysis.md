Insert **Code analysis** with `/code-analysis`. Set a question, repository, requested version, scope and budget. Start the investigation using your One model and personal Atlas connection.

The four phases save their results individually. After a stop or error, continue the open phase. Findings distinguish supporting evidence, counterexamples and remaining uncertainty. Flows and requirements link to the same read-only source cards; test references describe test code, not executed tests.

A new version remains a proposal until you accept it. The previous accepted analysis stays available, and the Versions tab compares findings. The Atlas code-analysis skill template now includes the corresponding investigation method.
