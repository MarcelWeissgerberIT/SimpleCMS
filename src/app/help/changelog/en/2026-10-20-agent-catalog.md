Open **Agents** to choose from twelve starters, grouped into Planning & projects, Coding & quality, Knowledge & documents, Communication, Integrations and General. Search by name or job, or filter by category. Recipes supplied by active integration profiles remain available under Integrations.

The new starters cover brief decomposition, code review, test planning, project checks through Atlas or another MCP connection, decisions, meetings and document analysis. Picking one opens an editable draft. Choose its source pages and any MCP connection, then save; these new specialists run manually and report their results. Repository changes and executed tests belong in Coding or Work orders.

Set a category in the agent editor to organise saved agents too. Older agents appear under General until you choose a category. The starter catalog stays available after you have saved your first agent.
