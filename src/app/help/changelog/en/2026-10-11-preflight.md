**Lamps, not lists.** Start opens with a panel: one lamp per kind of thing that waits on you — agent proposals, coding gates and questions, failed tasks, the inbox, a refused MCP token, slips in the Outbox, a stale mirror, a missed agent run. Amber waits, red is broken, grey cannot check right now. Counting happens in your browser: **0 tokens**.

**New lamps flash.** A lamp that turned on since you last looked flashes; **↵** on it or **MASTER CAUTION** acknowledges it — per device and person. In the morning One stays on Start with the full panel; later it folds to a strip.

**The queue.** ↵ on a lit lamp opens its cards, the most urgent first, each showing exactly what its key does: **A** apply, **D** discard, **E** the diff, **J / K** move, **Z** undo. **⇧A** applies the clean cards you have seen in full; cards that start the coding worker, go to Claude Code or send something out are **BY HAND** and wait for their own confirm key.

**Tidy by itself.** A newer mirror run replaces the older proposals you never opened; proposals nobody opened for a week gather as **STALE** with one discard. The logbook keeps the day on this device.

Settings → Appearance → Preflight switches it off or moves the start of the day. More in [Preflight](help:preflight).
