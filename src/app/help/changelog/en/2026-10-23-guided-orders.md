**Start a guided task …** uses a page as its starting point. The collapsible task companion shows goal, proposal, implementation, evidence and acceptance on the same plate.

The planner consults existing sources and answers first. Reversible assumptions are visible in the plan; questions are reserved for real blockers. Worker **1.26.1** includes the same quiet working rules for coding execution. Existing approvals and budgets remain in force.

A completed coding pipeline needs final QA, actually executed passing checks and your human decision before acceptance. Changed sources or work packages invalidate acceptance. **Prepare handoff to …** opens a draft for the selected MCP server, such as Atlas; external changes use its existing approval rules. Evidence and the decision are held on the executing device; the acceptance report is saved to the work order.
