Use **Insert tool** below Instructions to search One tools and the known tools of the MCP servers you selected. The selected name replaces highlighted text or is inserted at the cursor; Undo works as usual.

Under **Access**, MCP tool checkboxes are always available, even without an integration profile. Choose individual tools, use **Read-only tools**, **All** or **None**, and search long lists. Your saved choices remain in force when you reopen the editor.

Inserting a name in the instructions does not grant tool permissions. For an MCP server that has not been tested, test the connection in AI settings first to load its tool list.
