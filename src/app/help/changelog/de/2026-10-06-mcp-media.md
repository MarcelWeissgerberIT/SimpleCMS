Bild- und Video-Dienste, die MCP sprechen, funktionieren in One jetzt von Anfang bis Ende:

- **In One speichern.** Nutzt Claude so einen Server, erscheint jedes Bild, jeder Clip und jeder Ton, den er liefert, als Karte — Typ, Host, Größe — im KI-Menü, in `⌘K ?`, im KI-Terminal und in Agenten-Läufen. Geladen wird erst, wenn du **In One speichern** klickst: Die Datei wird geprüft (Typ und Inhalt), in diesem Browser gespeichert und kommt in die Seite. Im Terminal wartet sie als **Medien einfügen** auf deine Prüfung.
- **Generieren.** Tippe `/bild generieren` oder `/video generieren` — oder klick **Generieren…** in einem leeren Bildblock. Dienst wählen, Prompt schreiben, Seitenverhältnis und Anzahl wählen; Claude ruft nur diesen Server auf und wartet auf den Auftrag. Ein Ergebnis mit **Ansehen** prüfen, die passenden anhaken, **Auswahl einfügen**. Generieren kann Guthaben bei diesem Dienst verbrauchen.
- **Anmelden statt Token.** Server mit eigener Anmeldeseite bekommen unter Einstellungen → Claude AI → MCP-Server die Taste **Anmelden**. Kann die Anmeldung nicht zu One zurückkehren, geht es genauso mit **Mit Code anmelden**. Die Tokens liegen versiegelt in diesem Browser — nie in Backups oder Exporten.

Ein Host, der Browsern seine Dateien nicht gibt, bekommt **Öffnen** und **Kopie hochladen**; in einem Team-Arbeitsbereich auch **Über den Team-Server holen**. Mehr unter [MCP-Server](help:mcp-servers).
