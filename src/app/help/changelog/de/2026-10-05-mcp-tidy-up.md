Claude Desktop, Claude Code und andere MCP-Clients können jetzt auch umorganisieren, nicht nur lesen und schreiben: Seiten und Datenbanken im Baum verschieben, einen Eintrag in eine andere Datenbank mit passenden Eigenschaften verschieben, Datenbanken umbenennen, Eigenschaften und Ansichten ändern, Seiten, Einträge und ganze Datenbanken in den Papierkorb legen — bis zu 50 auf einmal — oder wiederherstellen.

- **Endgültig gelöscht wird nichts.** Eine Datenbank wandert mit ihren Einträgen in den Papierkorb, und jede Änderung lässt sich im **Agenten-Protokoll** rückgängig machen.
- **Du entscheidest.** Mit *Erst fragen* wartet jede Änderung auf einer Karte in deinem Tab — sie sagt, was geht, z. B. *Datenbank „Projects“ mit 8 Zeilen → Papierkorb*. Eine gesperrte Datenbank lehnt Strukturänderungen ab.
- **Das Codewort `one:`** — *„one: räum meine Projects-Datenbank auf“* — sagt Claude, dass es für die Anfrage One nutzen soll.

> Update nötig: In Claude Desktop die neue Erweiterung installieren (**Einstellungen → Agenten · MCP → Zu Claude Desktop hinzufügen**); für Claude Code `one-mcp.mjs` neu herunterladen.
