Der Arbeitsbereich trennt **Bearbeiten → Probelauf → Ausführen**. Der Probelauf-Status bezieht sich auf den tatsächlich geprüften Code und wird nach Änderungen ungültig. Ergebnisse früherer Stände werden deutlich gekennzeichnet. Beschreibe über dem Code den Zweck, damit andere wissen, wann sie das Script nutzen können; das Feld speichert beim Verlassen. **Hilfe & Funktionen** durchsucht Namen und Beschreibungen. **KI-Unterstützung** hat einen eigenen Tab; vorgeschlagenen Code prüfst du vor der Übernahme.

Der Script-Editor bietet jetzt wörtliches **Suchen und Ersetzen**, Groß-/Kleinschreibung, Navigation zum nächsten und vorherigen Treffer sowie **Gehe zu Zeile**. Alle Treffer lassen sich in einem rückgängig machbaren Schritt ersetzen. Eingaben in den Suchfeldern starten keinen Script-Lauf.

**Code im Fokus** schafft Platz, indem es die Referenz beziehungsweise den Abfrage-Builder ausblendet. Der Zeilenumbruch merkt sich deine Einstellung auf diesem Gerät. Eine Speicheranzeige zeigt, wann dein Code im Workspace angekommen ist; die Cloud-Synchronisierung bleibt separat sichtbar. Auch beim Auswerten einer Auswahl werden ausstehende Änderungen zuerst gespeichert.
