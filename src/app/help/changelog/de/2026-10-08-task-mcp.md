Es arbeiten zwei Claudes. **Deine MCP-Server in One** (Einstellungen → Claude KI → MCP-Server) gelten für Ones eigenen Claude: KI-Menü, Terminal, Agenten. Der Coding-Worker startet **Claude Code auf deinem Rechner** – und dort bekommt es nur die Aufgaben-Werkzeuge von One, solange die Setup-Seite des Workers nicht mehr erlaubt.

Das Coding-Panel zeigt das jetzt bei jeder Aufgabe: **Claude Code · MCP** mit den Servern, die ihre Stufen nutzen dürfen – beim Repo **Eigene MCP-Server für Claude Code**, bei einer Aufgabe ohne Repository **Aufgaben ohne Repository – eigene MCP-Server** – oder *nur die Aufgaben-Werkzeuge von One*.

Erwähnt der Text der Aufgabe einen deiner MCP-Server (Name oder Codewort), den Claude Code dort nicht nutzen darf – oder MCP überhaupt, solange es keinen hat –, sagt das Panel es, und **Setup-Seite öffnen** bringt dich hin. Trag den Namen so ein, wie `claude mcp list` ihn auf deinem Rechner zeigt, speichere und starte die Aufgabe erneut.

> Die Zeile braucht den neuesten Worker – lade ihn auf #/coding neu herunter.
