**Lesen.** Klick das Fähnchen eines Laufs an (oder setz ein Fenster mit <kbd>[</kbd> / <kbd>]</kbd>) und drück <kbd>↵</kbd> — oder **Fenster lesen** auf dem Schild. Der Dialog listet jede Stelle, die das Fenster geändert hat: Schema, Ansichten, Seiten, Zeilen, neue Zeilen. <kbd>↑</kbd> / <kbd>↓</kbd> gehen die Liste durch; daneben die Werte vorher → nachher und der Text Wort für Wort, in Tinte.

**Gehalten: seitdem geändert.** Eine Stelle, die nach dem Lauf jemand geändert hat — du, jemand aus dem Team, ein anderer Agent — trägt eine Raute auf dem Band und eine orange Markierung in der Liste: *2 Zeilen seitdem geändert (du) — sie werden gehalten.* Was ein anderer Schreiber mitten im Lauf getan hat, ist markiert (*enthält Änderungen von …*) und zählt nie zum Lauf.

**Ehrlich bei Lücken.** Ein Fenster, das die Strecke eines Schreibers schneidet, heißt *Teilweise* und bietet eine Taste, die sie ganz klammert; hat ein Tab geschlossen, bevor er aufschrieb, steht *Möglicherweise unvollständig* da.

**Vorfallbericht.** **Bericht** lädt eine Markdown-Datei: das Fenster, alle Schreiber darin, was sich geändert hat — Titel, Namen von Eigenschaften, Zahlen und Zeiten, nie ein Wert oder eine Zeile Text. Entsteht auf Knopfdruck, wird nirgends gespeichert. Lesen ändert nichts. Mehr unter [Flugschreiber](help:flight-recorder).
