**Feed** ist eine neue Datenbank-Ansicht: Jeder Eintrag ist eine Karte mit seinen Eigenschaften und seinem Inhalt, das Neueste zuerst — für Ankündigungen, Journale und blogartige Datenbanken. **Mehr anzeigen** klappt einen Beitrag an Ort und Stelle auf.

Neue Blöcke im `/`-Menü:
- `/formular` (englisch `/form`) — ein Formular mit drei Startfragen in einem Schritt.
- `/brotkrumen` — der Pfad zu dieser Seite; `/link zur seite` — ein Block-Link auf eine vorhandene Seite.
- `/4 spalten` und `/5 spalten`; `/pdf` zeigt ein PDF in einem Viewer direkt auf der Seite.
- Mehr Einbettungen: Google Docs, Sheets, Slides, Forms und Drive, Miro, Excalidraw, GitHub Gist, Spotify, Typeform, Calendly, Airtable, CodeSandbox, X und mehr.

In der Seitenleiste geht eine Datenbank jetzt wie ein Ordner auf: ihre Einträge in der Reihenfolge ihrer ersten Ansicht, **+** fügt einen hinzu, und eine Seite auf eine Datenbank gezogen wird zum Eintrag.
